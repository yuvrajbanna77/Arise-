# Arise Life RPG — Capacitor Android Starter

This starter wraps your supplied `app.src.html` as a local web app inside a Capacitor Android project. The uploaded HTML is copied without redesigning it to `www/index.html`.

## Important: what this ZIP is (and is not)

- It is a **Capacitor project starter**, not a prebuilt APK.
- The native `android/` folder is generated by `npx cap add android`; it is not included in the ZIP.
- A debug APK is unsigned for Play Store release. It can normally be installed directly on your own Android device after download, subject to Android's install warnings.
- The app uses local browser storage in its HTML. Test progress saving and export a backup before switching between browser/PWA and APK; those storage areas may be separate.
- Your HTML references Google Fonts from the internet. The interface may fall back to system fonts while offline.

## Build on a computer (official Capacitor workflow)

Requirements: Node.js 22+, Android Studio with an Android SDK installed, and a compatible Java/Gradle setup. Capacitor 8's current environment guidance lists Android Studio 2025.2.1 or newer.

1. Extract this ZIP.
2. Open a terminal in the extracted `Arise_Life_RPG_Capacitor_Starter` folder.
3. Run:

   ```bash
   npm install
   npx cap add android
   npx cap sync android
   npx cap open android
   ```

4. In Android Studio, wait for Gradle sync to finish.
5. Choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
6. Android Studio shows a link to the generated debug APK. Transfer it to your phone and install it.

Alternative terminal build after generating the Android folder:

```bash
npm run android:build:debug
```

Expected APK path: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Build without owning a computer (GitHub Actions cloud build)

The ZIP includes `.github/workflows/build-apk.yml`, which builds a debug APK on GitHub-hosted runners. You can trigger it from the GitHub website on your phone after the project files are in a GitHub repository.

1. Create a new repository on GitHub. If you want to keep the source private, set the repository to **Private**.
2. Upload the project files while preserving their paths, especially:
   - `www/index.html`
   - `package.json`
   - `capacitor.config.ts`
   - `.github/workflows/build-apk.yml`
3. Open the repository's **Actions** tab and enable Actions if GitHub asks.
4. Select **Build Arise Life RPG APK** > **Run workflow**.
5. Wait for the run to finish successfully.
6. Open the successful run, scroll to **Artifacts**, and download `Arise-Life-RPG-debug-APK`.
7. Extract the artifact ZIP on your phone; inside should be `app-debug.apk`. Install it after checking the source and Android's warning.

**Mobile upload note:** GitHub's mobile web UI may make uploading nested folders awkward. If you can't preserve the `.github/workflows/build-apk.yml` path, create the workflow using **Add file > Create new file** and enter the full path `.github/workflows/build-apk.yml`, then paste its contents from this ZIP. Likewise ensure the HTML is at `www/index.html`, not the repository root.

GitHub Actions usage limits may apply. Never put passwords, signing keys, or private tokens in the repository or workflow.

## After changing the HTML

Replace `www/index.html` with the updated HTML, then run:

```bash
npx cap sync android
```

Then rebuild the APK. The GitHub Actions workflow generates a fresh Android project each run, so it always uses the current `www/index.html`.

## Quick test checklist

- App opens and layout fits the phone screen.
- Complete a test quest; close and reopen the app; check whether XP/progress persists.
- Test export/import backup if your app provides it.
- Test without internet to identify any externally loaded assets that need a connection.
- Export a backup before reinstalling or changing app versions.
